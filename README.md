## 1. Описание используемых таблиц и форматов полей

### Блок управления продуктами и задачами
* **Таблица Products (Продукты):** Предназначена для хранения данных о продуктовых инициативах. Включает уникальный идентификатор `product_id` (формат `INT`) и наименование продукта `product_name` (формат строковый, `VARCHAR(50)`).
* **Таблица Projects (Проекты):** Служит для ведения проектов внутри продуктов. Содержит ключ `project_id` (`INT`), название проекта `project_name` (`VARCHAR(50)`), а также внешние ключи для связи: `product_id` (`INT`) указывает на родительский продукт, а `team_id` (`INT`) определяет команду-исполнителя.
* **Таблица Tasks (Задачи):** Хранит задачи по проектам. Содержит идентификатор `task_id` (`INT`) и название задачи `task_name` (строка расширенной длины, `VARCHAR(255)`). Связана с проектом через `project_id` (`INT`) и с исполнителем через `user_id` (`INT`). Время создания фиксируется в поле `date` (формат даты и времени, `TIMESTAMP`), текущий этап — в `status` (`VARCHAR(50)`), а время последних изменений — в `updated` (`TIMESTAMP`).

### Блок управления командами
* **Таблица Teams (Команды):** Описывает существующие рабочие группы. Содержит идентификатор `team_id` (`INT`) и название команды `team_name` (`VARCHAR(50)`).
* **Таблица Users (Пользователи):** Единый список участников системы. Хранит идентификатор `user_id` (`INT`), а также имя `fname` и фамилию `lname` в строковом формате (`VARCHAR(50)`).
* **Таблица Team_Members (Состав команд):** Таблица для связи многие ко многим. Связывает команды и пользователей через внешние ключи `team_id` (`INT`) и `user_id` (`INT`). Это позволяет легко распределять людей по разным командам.

---

## 2. План индексации 

* **Projects** по полю `product_id` — ускоряет получение списка всех проектов конкретного продукта.
* **Projects** по полю `team_id` — оптимизирует поиск проектов, закрепленных за определенной командой.
* **Tasks** по полю `project_id` — важный индекс для быстрой отрисовки задач внутри выбранного проекта.
* **Team_Members** по полю `user_id` — ускоряет проверку того, в каких именно командах состоит выбранный пользователь.

---

## 3. SQL-запрос для поиска неактивных задач

```sql
SELECT task_id, task_name, project_id, user_id, status, date, updated
FROM Tasks
WHERE COALESCE(updated, date) < DATE_TRUNC('month', CURRENT_DATE);
```
